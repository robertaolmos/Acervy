# Biblioteca – versão ORIGINAL (antes da refatoração)

App simples de gestão de biblioteca: cadastro de livros, lista de cadastrados, disponíveis, emprestados, pendentes de devolução e devolvidos.

- **Back end:** Python + Flask + SQLite (`app.py`, ~110 linhas)
- **Front end:** HTML + JavaScript puro (`static/index.html`, `static/script.js`, ~60 linhas)

## Como executar

    pip install -r requirements.txt
    python app.py

Acesse http://127.0.0.1:5000

Mudanças estão na branch develop.
